# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository owner privately through a verified contact method listed on their GitHub profile.

## Security notes

- Treat imported project files and user-authored HTML as untrusted input.
- Review generated framework exports before deploying them.
- Do not place API keys, credentials or private project data in this repository.
- Keep GitHub Actions permissions scoped to the minimum required for deployment.
